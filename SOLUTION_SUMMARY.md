# Резюме исправлений для проекта Sleep Stage Classifier

## Проблемы, которые были исправлены

### 1. Основная проблема с демо скриптом
**Ошибка**: `ValueError: The least populated class in y has only 1 member, which is too few`

**Причина**: Слишком короткие стадии сна (30 секунд) создавали только 1 сегмент на класс, что недостаточно для стратифицированного разделения данных.

**Решение**: 
- Увеличены длительности стадий с `[30, 30, 60, 30, 30]` до `[90, 90, 120, 90, 90]` секунд
- Увеличена общая длительность с 5 до 15 минут
- Теперь каждая стадия создает минимум 2 сегмента для корректного стратифицированного разделения

### 2. Проблемы в экстракторе признаков
**Проблемы**:
- Ошибки при вычислении энтропии с нулевыми значениями
- Деление на ноль в спектральных расчетах
- Ошибки при работе с пустыми гистограммами

**Исправления**:
- Добавлены проверки на пустые гистограммы во всех вычислениях энтропии
- Добавлена защита от деления на ноль в спектральных вычислениях
- Исправлены вычисления спектрального центроида и полосы пропускания

### 3. Конкретные изменения в коде

#### В `demo.py`:
```python
# Было:
stage_durations = [30, 30, 60, 30, 30]  # секунды
eeg_data, labels = create_synthetic_data(duration_minutes=5, ...)

# Стало:
stage_durations = [90, 90, 120, 90, 90]  # секунды - увеличены для обеспечения минимум 2 сегментов на класс
eeg_data, labels = create_synthetic_data(duration_minutes=15, ...)
```

#### В `src/features/extractor.py`:
- Исправлены все вычисления энтропии с проверками на пустые массивы
- Добавлена защита от деления на ноль в спектральных расчетах
- Исправлены вычисления спектрального центроида и полосы пропускания
