## 🔍 Структура детальных графиков

Каждый детальный график содержит 3 части:

### Верхний график: Оригинальные аннотации экспертов
- **Цвет**: Синий (#2E86AB)
- **Отображение**: Прямоугольники с подписями длительности
- **Подписи**: В минутах для длинных периодов, в секундах для коротких

### Средний график: Аннотации модели
- **Цвет**: Фиолетовый (#A23B72)
- **Отображение**: Прямоугольники по 8 секунд
- **Подписи**: "8с" для каждого периода

### Нижний график: Сравнение и пересечения
- **Зеленый**: Пересечения (True Positive)
- **Синий**: Только эксперты (False Negative)
- **Красный**: Только модель (False Positive)
- **Статистика**: Метрики качества на графике
