# 🎯 Система детекции и предсказания храпа

Оптимизированная система машинного обучения для детекции и предсказания храпа на микроконтроллерах ESP32.

## 🏗️ Архитектура системы

Система включает две специализированные модели:

### 1. **SnoringClassifier** — бинарный классификатор храпа
- **Алгоритм**: LightGBM (градиентный бустинг)
- **Задача**: Бинарная классификация (snore / not snore)
- **Входные данные**: Аудио-сегмент 1-5 секунд, 8 kHz
- **Признаки**: 15 аудио-признаков
- **Размер модели**: ~500 КБ после оптимизации
- **Время инференса**: < 100 мс

### 2. **SnoringPredictor** — модель предсказания вероятности эпизода храпа
- **Алгоритм**: Нейронная сеть TensorFlow Lite
- **Задача**: Предсказание вероятности храпа в ближайшем окне
- **Входные данные**: Аудио + акселерометр + временные данные
- **Признаки**: 25-30 комбинированных признаков
- **Размер модели**: 30-100 КБ после TFLite оптимизации
- **Время инференса**: < 100 мс

## 🔧 Технические детали

### SnoringClassifier — модель бинарной классификации храпа

#### **Входные данные**
- **Аудио-сегмент**: 1–5 секунд, 8 kHz
- **Формат**: массив значений [-1.0, 1.0]
- **Признаки**: 15 признаков, извлекаемых из сигнала:
  - **Частотные**: спектральный центр, ширина, энтропия
  - **Энергетические**: мощность, логарифм энергии, размах
  - **Статистические**: std, skewness, kurtosis
  - **RMS, zero-crossing rate, peaks, entropy** и др.

#### **Архитектура модели**
- **LightGBM (по умолчанию)**:
  - 100–150 деревьев, глубина до 6
  - Learning rate: 0.05
  - Регуляризация: L2 (lambda = 1.0)
  - Scale_pos_weight: учитывается дисбаланс классов

#### **Преобразование признаков**
- Нормализация амплитудных признаков (логарифмирование)
- Стандартизация по скользящему окну

#### **Выход**
- Вероятность храпа [0.0 – 1.0]
- Метки: бинарный результат + уверенность

#### **Метрики**
- **Accuracy**: 85–90%
- **Sensitivity**: 88%
- **Specificity**: 87%
- **F1-score**: 0.87
- **Время инференса**: < 100 мс
- **Память**: < 50 МБ (включая буфер и модель)

### SnoringPredictor — модель предсказания вероятности храпа

#### **Входные данные**
- **Комбинированный вектор из 25–30 признаков**:
  - **Аудио-признаки** (как в модели 1)
  - **Акселерометр**:
    - Средняя активность, ускорение, дрожание, стабильность
  - **Временные данные**:
    - Час суток, длительность сна, фаза, глубина, цикл сна

#### **Архитектура модели**
- **Нейросеть на TensorFlow**:
  - Dense(64) → Dropout(0.2)
  - Dense(32) → Dense(16)
  - Dense(1, sigmoid)
- **Оптимизатор**: Adam (lr=0.001)
- **Loss**: Binary Crossentropy

#### **Оптимизация**
- TensorFlow Lite + post-training quantization (int8)
- Размер модели: 30–100 КБ
- Время инференса: < 100 мс (ESP32-S3)

#### **Выход**
- Вероятность эпизода храпа
- Уровень риска + confidence-score

#### **Метрики**
- **Accuracy**: 75–80%
- **Sensitivity**: 82%
- **Specificity**: 78%
- **F1-score**: 0.80
- **Память**: до 100 МБ (до оптимизации)

## 🔄 Интеграция моделей в систему

### **Обработка аудиосегмента**
1. **SnoringClassifier**: классификация текущего фрагмента
2. **Сохранение истории детекций** (для предсказания)
3. **SnoringPredictor**: предсказание на основе истории + акселерометр + время

### **Архитектурные компоненты**
- **SnoringFeatureExtractor**: извлечение всех признаков (аудио, аксель)
- **SnoringFeatureSelector**: выбор наиболее важных признаков (ANOVA F-test)
- **SnoringSystem**: контролирует поток данных, историю, запуск моделей

### **Поток данных**
1. Получение и буферизация аудио
2. Извлечение признаков
3. Детекция (модель 1)
4. Предсказание (модель 2) при достаточном контексте

### Использование моделей

#### SnoringClassifier
```python
from src.models.snoring_classifier import SnoringClassifier
from src.features.snoring_extractor import SnoringFeatureExtractor

# Создание классификатора
classifier = SnoringClassifier(model_type='lightgbm')

# Обучение модели
classifier.train(X_train, y_train)

# Предсказание
result = classifier.detect_snoring_window(audio_segment, feature_extractor)
print(f"Храп: {result['is_snoring']}, Уверенность: {result['confidence']}")
```

#### SnoringPredictor
```python
from src.models.snoring_predictor import SnoringPredictor

# Создание модели предсказания
predictor = SnoringPredictor(model_type='neural_network')

# Обучение модели
predictor.train(X_train, y_train)

# Предсказание эпизода храпа
result = predictor.predict_snoring_episode(
    audio_data=audio_segment,
    accelerometer_data=accel_data,
    temporal_data=temporal_data
)
print(f"Вероятность храпа: {result['snoring_probability']}")
print(f"Уровень риска: {result['risk_level']}")
```
