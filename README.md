# 🎯 Snoring Classification System

Система классификации храпа на основе Decision Tree с извлечением 39 признаков из аудио и акселерометра.

## 🏗️ Архитектура

### 📊 Входные данные
- **Формат**: CSV файлы с сенсорными данными
- **Частота**: 10 измерений/сек
- **Каналы**: 
  - Аудио: `b100`, `b400`, `b1000`, `env`
  - Акселерометр: `x`, `y`, `z`
- **Размер файла**: 300 строк (30 секунд)

### 🔍 Обработка данных
- **Окно анализа**: 8 секунд (80 измерений)
- **Шаг**: 1 секунда (10 измерений)
- **Перекрытие**: 87.5% (7 из 8 секунд)
- **Временная шкала**: Непрерывная между CSV файлами

### 🧮 Признаки (39 всего)

#### 🎵 Аудио признаки (28)
- **7 признаков × 4 канала** (`b100`, `b400`, `b1000`, `env`):
  1. Средний уровень сигнала
  2. Максимальный уровень
  3. Изменчивость (стандартное отклонение)
  4. Относительная изменчивость
  5. Доля высоких значений
  6. Тенденция изменения
  7. Регулярность (автокорреляция)

#### 📱 Акселерометр (9)
- **3 признака × 3 оси** (`x`, `y`, `z`):
  1. Средняя активность движений
  2. Максимальная активность
  3. Доля времени с движением

#### 🔗 Смешанные признаки (2)
- `b400/b100` - отношение средних значений
- `b400/b1000` - отношение средних значений

### 🌳 Модель
- **Тип**: Decision Tree Classifier
- **Параметры**: 
  - `max_depth`: 3
  - `min_samples_leaf`: 5
  - `criterion`: gini
  - `class_weight`: balanced
- **Классы**: 2 (No Snoring / Snoring)

### 📝 Аннотации
- **Формат**: `_ann.txt` файлы
- **Метки**: `W` = храп, остальное время = нет храпа
- **Время**: Абсолютное время из названий CSV файлов

## 🔧 Использование

### Обучение модели
```python
from src.utils.data_loader import SnoringDataLoader
from src.models.decision_tree_classifier import SnoringDecisionTreeClassifier

# Загрузка данных
loader = SnoringDataLoader("snoring_data")
features, labels, feature_names = loader.load_all_data()

# Обучение
classifier = SnoringDecisionTreeClassifier()
training_results = classifier.train(features, labels, feature_names)
```

### Предсказания
```python
# Загрузка обученной модели
classifier.load_model("models/snoring_decision_tree.pkl")

# Предсказание
predictions, probabilities = classifier.predict(new_features)
```

### ESP32 интеграция
```c
#include "snoring_classifier_esp32.h"

float features[FEATURE_COUNT];
// ... извлечение признаков ...

int result = predict_snoring(features);
if (result == 1) {
    printf("Snoring detected!\n");
} else {
    printf("No snoring\n");
}
```
