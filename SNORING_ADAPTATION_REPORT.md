### Компоненты системы

#### 1. **SnoringFeatureExtractor**
- **15 специализированных признаков** для анализа храпа
- **Частотные диапазоны**: 20-800 Hz (храп), 0.1-2 Hz (дыхание)
- **Оптимизация для реального времени**
- **Поддержка аудио 8 kHz**

#### 2. **SnoringClassifier**
- **5 классов храпа**: No_Snoring, Light_Snoring, Heavy_Snoring, Snoring_Start, Snoring_End
- **Предсказание будущего храпа** с горизонтом 10-30 секунд
- **Оценка риска**: low, medium, high
- **Поддержка Random Forest, SVM, Logistic Regression**

#### 3. **ESP32 Integration**
- **Квантизованные модели** для микроконтроллеров
- **Оптимизированный C-код** для реального времени
- **Минимальное потребление памяти** (< 100KB)
- **Частота дискретизации 8 kHz**

## ⚡ ESP32 ОПТИМИЗАЦИЯ

### Ключевые оптимизации

1. **Квантизация признаков**
   ```c
   void quantize_features(float* features, int8_t* quantized) {
       for (int i = 0; i < NUM_FEATURES; i++) {
           float scaled = features[i] * QUANTIZATION_SCALE;
           if (scaled > 127) scaled = 127;
           if (scaled < -128) scaled = -128;
           quantized[i] = (int8_t)scaled;
       }
   }
   ```

2. **Оптимизированное дерево решений**
   ```c
   int predict_snoring_class(int8_t* quantized_features) {
       int node = 0;
       while (tree_children_left[node] != -1) {
           int feature_idx = tree_feature[node];
           int8_t threshold = tree_threshold[node];
           
           if (quantized_features[feature_idx] <= threshold) {
               node = tree_children_left[node];
           } else {
               node = tree_children_right[node];
           }
       }
       return node % NUM_CLASSES;
   }
   ```
