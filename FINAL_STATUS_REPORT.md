## 🔧 ИНСТРУКЦИИ ПО ИСПОЛЬЗОВАНИЮ

### 1. **Быстрый старт**
```bash
# Установка зависимостей
pip install -r requirements.txt

# Обучение модели
python train_snoring_classifier.py

# Тестирование
python test_feature_extraction.py
python test_model_prediction.py

# Экспорт для ESP32
python export_to_tflite.py
```

### 2. **Интеграция с ESP32**
```c
#include "snoring_classifier_esp32.h"

float features[FEATURE_COUNT];
// ... извлечение признаков ...

int result = predict_snoring(features);
if (result == 1) {
    printf("Snoring detected!\n");
} else {
    printf("No snoring\n");
}
```

### 3. **Формат данных**
- **CSV**: колонки `b100`, `b400`, `b1000`, `env`, `x`, `y`, `z`
- **Аннотации**: `_ann.txt` с периодами "W" (храп)
- **Время**: из названий файлов (например, `3_100917.csv`)
