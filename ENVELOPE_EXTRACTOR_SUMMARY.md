## 🔬 Технические детали

### **Алгоритм извлечения огибающих:**
```python
def extract_envelopes(self, audio_data, band_name):
    # 1. Полосовая фильтрация
    b, a = signal.butter(4, [low_norm, high_norm], btype='band')
    filtered_signal = signal.filtfilt(b, a, audio_data)
    
    # 2. Детектор огибающей (преобразование Гильберта)
    analytic_signal = signal.hilbert(filtered_signal)
    envelope = np.abs(analytic_signal)
    
    # 3. Разделение на 10 сегментов
    segment_length = len(envelope) // 10
    envelopes = []
    
    for i in range(10):
        start_idx = i * segment_length
        end_idx = start_idx + segment_length
        segment = envelope[start_idx:end_idx]
        
        # 4. Извлечение признаков для каждого сегмента
        features = self._extract_envelope_features(segment)
        envelopes.extend(features)
    
    return np.array(envelopes)
```

### **Признаки огибающих:**
```python
def _extract_envelope_features(self, envelope_segment):
    return [
        np.mean(envelope_segment),      # Среднее
        np.std(envelope_segment),       # Стандартное отклонение
        np.max(envelope_segment),       # Максимум
        np.min(envelope_segment),       # Минимум
        np.max(envelope_segment) - np.min(envelope_segment)  # Размах
    ]
```
