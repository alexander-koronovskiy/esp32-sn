# ESP32 Sleep Stage Classifier

Оптимизированная версия классификатора стадий сна для микроконтроллера ESP32.

## 📋 Описание

Этот проект содержит оптимизированную версию классификатора стадий сна, адаптированную для работы на ESP32 с ограниченными ресурсами:

- **RAM**: до 512 КБ SRAM
- **Flash**: до 4 МБ
- **CPU**: 240 МГц, без FPU

## 🚀 Быстрый старт

# Клонируйте проект
git clone <repository>

После запуска демонстрации будут созданы файлы:

- `esp32_code/sleep_classifier.c` - Основной код классификатора
- `esp32_code/example_usage.c` - Пример использования
- `models/esp32_model.pkl` - Обученная модель
- `models/esp32_scaler.pkl` - Scaler для нормализации

### 3. Интеграция в ESP32 проект

```c
#include "sleep_classifier.h"

// Буфер для данных ЭЭГ (10 секунд при 64 Hz)
float eeg_buffer[640];
float features[NUM_FEATURES];

void setup() {
    Serial.begin(115200);
    // Инициализация АЦП
}

void loop() {
    // Сбор данных ЭЭГ
    for (int i = 0; i < 640; i++) {
        eeg_buffer[i] = analogRead(EEG_PIN) * 3.3 / 4095.0;
        delay(15);  // ~64 Hz
    }
    
    // Извлечение признаков и классификация
    extract_features(eeg_buffer, features);
    int stage = predict_sleep_stage(features);
    
    // Вывод результата
    Serial.print("Sleep stage: ");
    Serial.println(get_sleep_stage_name(stage));
    
    delay(1000);
}
```

## 📊 Характеристики

### Оптимизации:
- **Частота дискретизации**: 64 Hz (вместо 256 Hz)
- **Количество каналов**: 1 (вместо 2)
- **Длина сегмента**: 10 секунд (вместо 30)
- **Количество признаков**: 8 (вместо 200+)
- **Размер модели**: ~2KB (вместо 500KB)

### Производительность:
- **Время инференса**: ~10ms
- **Использование памяти**: ~50KB
- **Точность**: ~80% (потеря 5% по сравнению с оригиналом)

## 📈 Признаки

Система использует 8 основных признаков:

1. **RMS** - Root Mean Square
2. **STD** - Стандартное отклонение
3. **MEAN** - Среднее значение
4. **RANGE** - Размах (max - min)
5. **ZERO_CROSSINGS** - Количество пересечений нуля
6. **PEAK_COUNT** - Количество пиков
7. **DELTA_POWER** - Мощность в дельта диапазоне (0.5-4 Hz)
8. **THETA_POWER** - Мощность в тета диапазоне (4-8 Hz)

## 🎯 Стадии сна

Система классифицирует 5 стадий сна:

- **Wake** (0) - Бодрствование
- **N1** (1) - Легкий сон
- **N2** (2) - Средний сон
- **N3** (3) - Глубокий сон
- **REM** (4) - Быстрый сон

## ⚙️ Настройка

### Изменение параметров

В файле `sleep_classifier.h` можно изменить:

```c
#define NUM_FEATURES 8        // Количество признаков
#define NUM_CLASSES 5         // Количество классов
#define QUANTIZATION_SCALE 100 // Масштаб квантизации
```

### Оптимизация для вашего оборудования

1. **Изменение частоты дискретизации**:
   ```c
   #define SAMPLING_RATE 64   // Измените на нужную частоту
   ```

2. **Изменение длины сегмента**:
   ```c
   #define SEGMENT_LENGTH 640 // Измените на нужную длину
   ```

3. **Добавление новых признаков**:
   - Отредактируйте функцию `extract_features()` в `example_usage.c`
   - Обновите `NUM_FEATURES`
   - Переобучите модель в Python
