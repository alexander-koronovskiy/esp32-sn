## 🎯 **ОБЩАЯ АРХИТЕКТУРА СИСТЕМЫ**

### **Два основных компонента:**

#### **1. ДЕТЕКЦИЯ ХРАПА (Мгновенная)**
- **Цель**: Определить наличие и тип храпа в текущий момент
- **Входные данные**: Аудио сигнал (8 kHz, 1-секундные окна)
- **Выход**: 5 классов храпа + уверенность
- **Частота обновления**: 1 раз в секунду

#### **2. ПРЕДСКАЗАНИЕ ХРАПА (Проактивная)**
- **Цель**: Прогнозировать наступление храпа через 10-30 секунд
- **Входные данные**: Положение головы + время сна + контекст
- **Выход**: Вероятность храпа + временной горизонт + рекомендации
- **Частота обновления**: Каждые 10 секунд

## 🔧 **ТЕХНИЧЕСКАЯ АРХИТЕКТУРА**

### **МОДЕЛЬ 1: Детекция храпа (SnoringClassifier)**

```python
class SnoringClassifier:
    """
    Классификатор для мгновенной детекции храпа
    """
    
    # Классы храпа
    classes = [
        'No_Snoring',      # Отсутствие храпа
        'Light_Snoring',   # Легкий храп
        'Heavy_Snoring',   # Сильный храп
        'Snoring_Start',   # Начало храпа
        'Snoring_End'      # Конец храпа
    ]
    
    # Признаки (15 основных)
    features = [
        'snoring_intensity',           # Интенсивность храпа
        'breathing_rate',              # Частота дыхания
        'breathing_amplitude',         # Амплитуда дыхания
        'breathing_regularity',        # Регулярность дыхания
        'snoring_periodicity',         # Периодичность храпа
        'snoring_regularity',          # Регулярность храпа
        'spectral_centroid',           # Спектральный центроид
        'spectral_rolloff',            # Спектральный спад
        'spectral_bandwidth',          # Спектральная ширина
        'spectral_entropy',            # Спектральная энтропия
        'autocorrelation_peak',        # Пик автокорреляции
        'autocorrelation_decay',       # Спад автокорреляции
        'harmonic_ratio',              # Соотношение гармоник
        'noise_level',                 # Уровень шума
        'signal_quality'               # Качество сигнала
    ]
```

### **МОДЕЛЬ 2: Предсказание храпа (SnoringPredictor)**

```python
class SnoringPredictor:
    """
    Модель для предсказания будущего храпа
    """
    
    # Входные параметры
    input_features = [
        'head_position_angle',         # Угол наклона головы
        'head_rotation',               # Поворот головы
        'head_height',                 # Высота головы
        'position_duration',           # Длительность в позиции
        'sleep_duration',              # Длительность сна
        'sleep_phase',                 # Фаза сна (если доступна)
        'sleep_depth',                 # Глубина сна
        'sleep_cycles',                # Циклы сна
        'time_of_night',              # Время ночи
        'previous_snoring_history'    # История храпа
    ]
    
    # Выходные параметры
    output_predictions = [
        'snoring_probability',         # Вероятность храпа
        'time_horizon',               # Временной горизонт (10-30 сек)
        'risk_level',                 # Уровень риска (low/medium/high)
        'recommendation'              # Рекомендация
    ]
```

## 📊 **ПРИНЦИПЫ РАБОТЫ**

### **ДЕТЕКЦИЯ ХРАПА:**

1. **Аудио обработка**:
   - Частота дискретизации: 8 kHz
   - Длина окна: 1 секунда (8000 сэмплов)
   - 10 частотных диапазонов для анализа

2. **Извлечение признаков**:
   - 15 специализированных признаков храпа
   - Анализ 10 огибающих для каждого диапазона
   - Спектральный анализ + временной анализ

3. **Классификация**:
   - Random Forest / SVM / Logistic Regression
   - Точность: 85-90%
   - Время обработки: < 100ms

### **ПРЕДСКАЗАНИЕ ХРАПА:**

1. **Анализ положения**:
   - Угол наклона головы (критично для храпа)
   - Поворот головы (влияет на проходимость дыхательных путей)
   - Высота головы (влияет на положение языка)

2. **Временной анализ**:
   - Длительность в текущей позиции
   - Общая длительность сна
   - Фаза сна (если доступна)

3. **Контекстный анализ**:
   - История храпа за ночь
   - Время ночи
   - Предыдущие эпизоды

4. **Прогнозирование**:
   - Вероятность храпа через 10-30 секунд
   - Уровень риска (low/medium/high)
   - Конкретные рекомендации

## 🎯 **ЛОГИКА ПРЕДСКАЗАНИЯ**

### **Критерии риска храпа:**

#### **Позиционные факторы:**
- **Высокий риск**: Голова запрокинута назад > 30°
- **Средний риск**: Голова повернута в сторону > 45°
- **Низкий риск**: Голова в нейтральном положении

#### **Временные факторы:**
- **Высокий риск**: В позиции > 5 минут
- **Средний риск**: В позиции 2-5 минут
- **Низкий риск**: В позиции < 2 минут

#### **Контекстные факторы:**
- **Высокий риск**: Глубокая фаза сна + неподходящая позиция
- **Средний риск**: Легкая фаза сна + неподходящая позиция
- **Низкий риск**: Любая фаза + подходящая позиция
