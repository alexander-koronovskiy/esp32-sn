# 🔄 Адаптация SnoringClassifier для 2-классовой классификации

## 📋 Обзор

Данный документ описывает адаптацию системы детекции храпа с 3-классовой на 2-классовую классификацию для работы с реальными данными.

## 🎯 Проблема

### **Исходная система ожидала:**
- **3 класса:** `No_Snoring`, `Light_Snoring`, `Heavy_Snoring`
- **Признаки:** 50 комбинированных признаков (аудио + акселерометр + поза)
- **Формат данных:** Синтетические аудио данные

### **Реальные данные содержат:**
- **2 класса:** `W` (Wake/No Snoring), отсутствие метки (Snoring)
- **Признаки:** 25 колонок из CSV (нейронные сети + полосовые фильтры + акселерометр)
- **Формат данных:** CSV файлы с предобработанными признаками

## 🔧 Решение

### **1. Создан SnoringClassifier2Class**

**Файл:** `src/models/snoring_classifier_2class.py`

**Ключевые особенности:**
- **2 класса:** `['No_Snoring', 'Snoring']`
- **Маппинг меток:** `W` → `No_Snoring`, `''` → `Snoring`
- **Поддержка реальных данных:** CSV формат с 25 колонками
- **Совместимость:** Работает как с реальными, так и с синтетическими данными

**Структура признаков:**
```python
# Акселерометр (3)
accel_x, accel_y, accel_z

# Физиологические данные (3)
bpm, bpm_by_nn, bpm_by_acf

# Нейронные сети (4)
breath_nn, snore_nn, signal_nn, splash_nn

# Полосовые фильтры (3)
b100, b400, b1000

# Дополнительные признаки (12)
mf, af, arf, sf, r_th, status_1,2,3, ml, eog, env
```

### **2. Скрипт загрузки реальных данных**

**Файл:** `load_real_data.py`

**Функции:**
- Загрузка CSV файлов из `snoring_data/`
- Парсинг аннотаций из `*_ann.txt`
- Создание меток на основе временных интервалов
- Подготовка данных для обучения

**Формат аннотаций:**
```
W,23:57:46.573,00:08:40.082  # W = No Snoring
W,00:08:52.291,00:08:54.349  # W = No Snoring
# Отсутствие метки = Snoring
```

### **3. Демонстрационный скрипт**

**Файл:** `demo_2class_classifier.py`

**Возможности:**
- Тестирование на синтетических данных
- Тестирование на реальных данных
- Сравнение производительности
- Сохранение обученных моделей

### **4. ESP32 код для 2 классов**

**Файл:** `esp32_code/snoring_detector_2class.c`

**Изменения:**
- **2 класса:** `SNORING_NO` (0), `SNORING_YES` (1)
- **Упрощенная классификация:** Эвристическая логика
- **Оптимизация:** Фиксированные буферы, минимальные вычисления

## 🚀 Использование

### **1. Обучение модели**

```python
from src.models.snoring_classifier_2class import SnoringClassifier2Class

# Создание классификатора
classifier = SnoringClassifier2Class(model_type='random_forest')

# Обучение на реальных данных
training_result = classifier.train(X, y, data_type='csv')

print(f"Точность: {training_result['accuracy']:.3f}")
```

### **2. Предсказание**

```python
# Предсказание на новых данных
prediction = classifier.predict(new_data, data_type='csv')

print(f"Класс: {prediction['class']}")
print(f"Вероятность храпа: {prediction['p_snore']:.3f}")
print(f"Есть храп: {prediction['is_snoring']}")
```

### **3. Загрузка реальных данных**

```bash
# Загрузка и подготовка данных
python3 load_real_data.py

# Демонстрация
python3 demo_2class_classifier.py
```

## 🔄 Миграция с 3 классов

### **Автоматическая конвертация:**
```python
# Старый классификатор (3 класса)
old_classifier = SnoringClassifier()

# Новый классификатор (2 класса)
new_classifier = SnoringClassifier2Class()

# Конвертация меток
y_2class = new_classifier.convert_real_data_labels(y_3class)
```

### **Совместимость:**
- **Обратная совместимость:** Работает с 3-классовыми данными
- **Автоматическое определение:** Тип данных определяется автоматически
- **Плавный переход:** Постепенная миграция без потери функциональности
