# Decision Tree Классификатор Храпа - Архитектура (Исправленная)

## Обзор

Реализован Decision Tree классификатор для детекции храпа согласно техническому заданию. Модель использует ровно 30 признаков и классифицирует на **2 класса** с ограничениями сложности для развертывания на ESP32.

## Анализ реальной разметки

Из анализа реальных данных выявлено:
```
Распределение меток: {np.str_(''): 25020}
```

**2 класса в реальных данных:**
- **Пустая строка `''`** = храп присутствует (Snoring)
- **Отсутствие метки** = также интерпретируется как храп

**Примечание:** В исходном ТЗ предполагалось 3 класса (No Snoring / Light Snoring / Heavy Snoring), но реальная разметка содержит только 2 класса.

## Архитектура

### Входные данные
- **Частота данных**: 10 раз в секунду (10 тиков за секунду)
- **Окно**: 1 секунда (8000 сэмплов при частоте дискретизации 8 кГц)
- **Шаг**: 1 секунда

### Датчики
- **4 аудиоканала** с полосовой фильтрацией:
  - **Breath**: 100-400 Гц (дыхание)
  - **Snore**: 400-1000 Гц (зона храпа)
  - **Speech**: 1000-4000 Гц (речь и шумы)
  - **High**: 4000-7000 Гц (высокочастотный фон)

- **Акселерометр**: 3 оси (X, Y, Z) для измерения движений и вибраций

### 30 Признаков

#### 1. Аудио признаки (20 признаков)
**5 признаков × 4 полосы = 20 признаков**

Для каждой частотной полосы извлекаются:
- **Mean**: средний уровень сигнала
- **Max**: максимальный уровень
- **Std**: стандартное отклонение (изменчивость)
- **Доля выше порога**: доля времени выше 75-го процентиля
- **Тренд**: наклон линейной регрессии по времени

#### 2. Акселерометр (7 признаков)
- **Средняя амплитуда |Δ|** по X/Y/Z (3 признака)
- **Максимальная амплитуда |Δ|** по X/Y/Z (3 признака)
- **Доля подвижных тиков** (1 признак)

#### 3. Смешанные признаки (3 признака)
- **Snore/Breath**: отношение храпового диапазона к дыхательному
- **Snore/Speech**: отношение храпа к речи/шуму
- **Breath_autocorr_lag1**: автокорреляция дыхания (регулярность)

## Модель

### Decision Tree с ограничениями сложности
- **max_depth ≤ 5**: максимальная глубина дерева
- **min_samples_leaf ≥ 10**: минимальное количество сэмплов в листе
- **criterion**: 'gini' или 'entropy' (по валидации)
- **class_weight**: 'balanced' для несбалансированных классов

### Выход
**2 класса** (согласно реальной разметке):
- **0**: No Snoring (храп отсутствует) - метка 'W'
- **1**: Snoring (храп присутствует) - пустая строка ''

## Постобработка

### 1. Медианный фильтр
- **Окно**: 3 соседних окна (0.3 секунды)
- **Цель**: устранение шумовых выбросов

### 2. Гистерезис фильтр
- **Подтверждение храпа**: ≥3 окон подряд не-No
- **Завершение эпизода**: ≥3 окон подряд No
- **Цель**: устойчивость к кратковременным изменениям

## Нормализация

### Робастная нормализация (median+IQR)
- **Метод**: RobustScaler из scikit-learn
- **Преимущества**: устойчивость к выбросам
- **Применение**: ко всем 30 признакам одновременно

## Ресурсы

### Размер модели
- **Цель**: ~1-5 КБ (int8)
- **Текущая реализация**: ~10-50 КБ (зависит от глубины дерева)

### Производительность
- **Инференс**: ≪ 50 мс на ESP32
- **Память**: минимальная (только дерево решений)
