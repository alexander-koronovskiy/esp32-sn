# 🔍 Принципиальная разница: Регистрация vs Предсказание храпа

## 📊 Обзор двух подходов

В системе ML Snoring используются **два принципиально разных алгоритма**:

1. **🎯 Регистрация храпа** - детекция текущего состояния
2. **🔮 Предсказание храпа** - прогноз будущего состояния

---

## 🎯 **АЛГОРИТМ РЕГИСТРАЦИИ ХРАПА**

### **Принцип работы:**

### **Ключевые характеристики:**

#### **⏰ Временной фокус:**
- ✅ **Текущий момент** - анализ "здесь и сейчас"
- ✅ **Реальное время** - мгновенная обработка
- ✅ **Окно анализа** - 1 секунда аудио

#### **🎵 Анализируемые данные:**
- ✅ **Текущий аудио сегмент** (8000 сэмплов)

#### **📊 Выходные данные:**

#### **🔧 Алгоритмические особенности:**
- ✅ **Прямая классификация** - вход → выход
- ✅ **Статический анализ** - без учета истории
- ✅ **Мгновенная реакция** - задержка < 1 секунды
- ✅ **Высокая точность** - 85-90% для текущего состояния

## 🔮 **АЛГОРИТМ ПРЕДСКАЗАНИЯ ХРАПА**

### **Принцип работы:**
```python
def predict_snoring_future(self, current_features, history_features, time_horizon=30):
    # 1. Объединение ТЕКУЩИХ и ИСТОРИЧЕСКИХ признаков
    combined_features = np.concatenate([current_features, history_features])
    
    # 2. Анализ ТРЕНДОВ и ПАТТЕРНОВ
    trend_analysis = self._analyze_trends(history_features)
    
    # 3. Прогноз БУДУЩЕГО состояния
    future_prediction = self._predict_future(combined_features, time_horizon)
    
    # 4. Оценка РИСКА храпа
    risk_assessment = self._assess_risk(future_prediction)
```

### **Ключевые характеристики:**

#### **⏰ Временной фокус:**
- ✅ **Будущее время** - прогноз через 10-30 секунд
- ✅ **Исторический анализ** - учет прошлых данных
- ✅ **Тренд-анализ** - выявление паттернов

#### **🎵 Анализируемые данные:**
- ✅ **Текущие признаки** + **Исторические признаки**
- ✅ **Временные ряды** (последние 5-10 сегментов)
- ✅ **Тренды и паттерны** (нарастание/затухание)
- ✅ **Контекстная информация** (время сна, фазы)

#### **📊 Выходные данные:**
```python
{
    'snoring_probability': 0.75,        # Вероятность храпа через 30 сек
    'no_snoring_probability': 0.25,     # Вероятность отсутствия храпа
    'risk_level': 'high',               # Уровень риска (low/medium/high)
    'time_horizon_seconds': 30,         # Горизонт предсказания
    'prediction_confidence': 0.82,      # Уверенность в прогнозе
    'class_probabilities': {...}         # Вероятности будущих классов
}
```

#### **🔧 Алгоритмические особенности:**
- ✅ **Временной анализ** - учет истории и трендов
- ✅ **Паттерн-распознавание** - выявление циклов храпа
- ✅ **Риск-анализ** - оценка вероятности будущего храпа
- ✅ **Контекстная обработка** - учет времени и условий

## 🧠 **АЛГОРИТМИЧЕСКИЕ ДЕТАЛИ**

### **Регистрация (Детекция):**

```python
# Простой алгоритм классификации
def register_snoring(audio_segment):
    # 1. Извлечение признаков
    features = extract_features(audio_segment)
    
    # 2. Классификация
    class_id = classifier.predict(features)
    
    # 3. Результат
    return {
        'is_snoring': class_id in [1, 2, 3],
        'intensity': get_intensity(class_id),
        'confidence': get_confidence(features)
    }
```

**Сложность:** O(n) где n = размер сегмента

### **Предсказание (Прогноз):**

```python
# Сложный алгоритм прогнозирования
def predict_snoring(current_features, history_features, time_horizon):
    # 1. Анализ трендов
    trends = analyze_trends(history_features)
    
    # 2. Паттерн-распознавание
    patterns = recognize_patterns(history_features)
    
    # 3. Временной анализ
    temporal_features = extract_temporal_features(history_features)
    
    # 4. Объединение признаков
    combined_features = combine_features(current_features, trends, patterns, temporal_features)
    
    # 5. Прогноз
    future_prediction = predict_future(combined_features, time_horizon)
    
    # 6. Оценка риска
    risk = assess_risk(future_prediction, patterns)
    
    return {
        'snoring_probability': future_prediction,
        'risk_level': risk,
        'confidence': calculate_confidence(patterns)
    }
```

**Сложность:** O(m × n) где m = история, n = размер признаков

```python
# Регистрация - каждую секунду
while True:
    audio_segment = get_audio_segment()
    current_status = classifier.detect_snoring_window(audio_segment)
    
    if current_status['is_snoring']:
        send_alert("Храп обнаружен сейчас!")
        break

# Предсказание - каждые 10 секунд
if has_sufficient_history():
    future_prediction = classifier.predict_snoring_future(
        current_features, history_features, time_horizon=30
    )
    
    if future_prediction['risk_level'] == 'high':
        send_warning("Храп ожидается через 30 секунд!")
```

### **Сценарий 2: Адаптивная система**

```python
# Комбинированный подход
def adaptive_snoring_system():
    # Регистрация текущего состояния
    current = register_current_snoring()
    
    # Предсказание будущего
    future = predict_future_snoring()

    elif not current['is_snoring'] and future['risk_level'] == 'high':
        # Профилактические меры
        take_preventive_action()

        # Временная ситуация - мониторинг
```
